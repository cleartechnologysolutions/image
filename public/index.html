How to use & privacy

Blackout, circle or highlighter: click a detected word, or drag to select an area. Arrow: start on the target, then drag outward. Arrow + note: draw the same way, then release to open the text prompt. Number: click to place the next marker. Escape cancels a pending action. Ctrl/Cmd+Z undoes; Ctrl/Cmd+Shift+Z redoes. OCR can miss text, so inspect your exported image. Drag always works. Highlighter is translucent and does not hide sensitive text; use Blackout for redaction.

Blackouts replace pixels in exported images; they are not removable layers. Undo and the original image remain available in this tab until it is closed or replaced. Nothing is saved to a server. Text recognition runs locally using downloaded OCR assets. Exporting includes only the rendered pixels, not source metadata.
